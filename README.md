# MaurePS5
A experimental PS5 Translation layer for Windows, MacOS and Linux

## Goal

Our goal for MaurePS5 is **run PS5 games without a powerful PC**.
Main platform for MaurePS5 is Windows. With Linux or maybe macOS support, FreeBSD, NetBSD and OpenBSD are platforms that we will support in the future. 

## Status

MaurePS5 has a **command processor, memory tracker, syscall layer, shader recompiler(just the backend) and a tiled memory to linear memory**. More code will be added soon.

Shaders translated: 1166/1166

Syscalls translated: 131/723(most syscalls are stubs)

No game can boot yet in the translation layer.
